# Launch posts: Base (free alternative to Airtable)

App: https://s3eidat.github.io/base/
Guide: https://s3eidat.github.io/guides/base/

Facts you can say (all true in the code): free, no account, no record cap (only the browser's storage), data and
attachments stay in the browser (IndexedDB), works offline after first load, several bases and tables, 15 field
types incl. links between tables (both sides kept in sync) and attachments, grid with keyboard editing and
paste from spreadsheets, kanban (drag cards), calendar (drag records between days), gallery with photo covers,
per-view filters/sorts/hidden fields, search, sum row, CSV import with type guessing, CSV export, templates,
backup file with attachments, undo.
Not true / don't claim: formulas, rollups, lookups, forms, automations, API, comments, sharing or sync, mobile
app, Arabic interface (Arabic text in records works).

## AlternativeTo (suggest as alternative to Airtable)

**Name:** S3eidat Base
**Short description:** Free, private spreadsheet-database in the browser: typed fields, linked records, kanban, calendar, gallery.
**Description:**
Base lets you build tables with real field types (text, numbers, currency, dates, single and multiple select,
checkbox, rating, URL, email, phone, attachments) and link records between tables, with the link showing on both
sides. Work in a spreadsheet-like grid with keyboard editing and paste from Excel or Sheets, or switch to a kanban
board, a month calendar or a photo gallery. Each view keeps its own filters, sorts and hidden fields. Import CSV
with automatic field types and export any view. There is no record cap and no account: everything, attachments
included, stays in your browser and works offline. No formulas, automations or sharing yet.
**Tags:** database, spreadsheet, kanban, no-code, privacy, offline, no-signup
**License:** Free. **Platforms:** Web (any modern browser, desktop and mobile).

## Show HN

**Title:** Show HN: An Airtable-style database that runs entirely in your browser, no record limit

**First comment:**
Base is a static page: tables with typed fields, two-way linked records, attachments stored as Blobs in IndexedDB,
and grid/kanban/calendar/gallery views with per-view filters and sorts. The grid behaves like a spreadsheet
(arrows, Enter to edit, type to replace, paste a block from Excel), CSV import guesses field types (numbers,
dates, currency, email, URL, checkbox, option lists), and the whole base plus attachments exports to one JSON
backup.

No network calls (CSP connect-src 'self'), plain JS, no build. Known gaps: no formulas/rollups, forms or
automations, and no sharing since there's no server. I'd like to know which of those you'd miss first.

Disclosure: I made this. It's free, there's no account, and your data stays on your device.

You make tables with proper field types (dates, options, checkboxes, attachments, links to other tables) and work
in a spreadsheet-like grid, a kanban board you can drag cards on, a calendar, or a photo gallery. Filters, sorts
and hidden fields are saved per view. You can import a CSV (it guesses the column types) or paste straight from
