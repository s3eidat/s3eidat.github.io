## Show HN

**Title:** Show HN: A link-in-bio page builder that exports one static HTML file you host yourself

**First comment:**
Link Page is a static editor: you build the page with a live preview (a sandboxed srcdoc iframe rendering the exact
export), and it downloads a single index.html with inline CSS, photos as data URLs, and zero JavaScript. Hosting is
up to you; the Publish tab walks through Netlify Drop, GitHub Pages and Cloudflare Pages. The QR code comes from a
small byte-mode encoder written for this (tested by decoding with jsQR across versions and masks).

No network calls from the editor (CSP connect-src 'self'), plain JS, no build. No analytics or scheduling, since
the page has no scripts. Would you want an optional vCard "save contact" button next?
