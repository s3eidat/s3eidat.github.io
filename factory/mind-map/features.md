# Mind Map — features (browser-only)

## Must (core)
- Central topic with balanced auto layout (branches left and right), curved coloured branches.
- Keyboard-first: Tab adds a child, Enter a sibling, F2/typing edits, Delete removes, arrows move around,
  Space collapses/expands, Ctrl+Z/Y undo/redo.
- Drag a topic onto another to move it there; Alt+↑/↓ reorders; drag a main branch to the other side.
- Collapse/expand, branch colours (auto, or pick), icons (small built-in emoji set), notes on a topic.
- Pan/zoom/fit, export PNG and SVG, Markdown outline export, outline import (Markdown, indented text).
- Several maps saved in the browser, save/open file.

## Should (full)
- Export PDF (image), FreeMind .mm import, themes (light, dark, colourful), search/jump to a topic,
  touch support (tap, double-tap, drag, pinch), mobile toolbar, empty state + templates, S3_SELFTEST, offline.

## Could (later)
- Images and links in topics, presentation mode, OPML, cross-links between branches.
