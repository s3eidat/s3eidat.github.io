# Link Page — features (browser-only)

## Must (core)
- Profile: avatar (upload, auto square crop and resize, embedded), name, bio (RTL works), optional verified-style
  tick is NOT offered (would imply verification).
- Blocks: link buttons (title, URL, optional emoji, on/off, featured), section headers, text notes; add, edit,
  delete, reorder (drag and up/down), duplicate.
- Social icons row (Instagram, TikTok, YouTube, X, Facebook, LinkedIn, WhatsApp, Telegram, Snapchat, GitHub,
  Spotify, email, phone, website) with own hand-drawn simple glyphs; handle or URL is turned into a link; top or
  bottom placement.
- Themes: 10+ presets plus custom background (solid, gradient, image), button fill/outline/soft/shadow, corner
  radius, colours, system font stacks (no web fonts), page direction LTR/RTL.
- Live phone preview that is the exact exported HTML (sandboxed iframe, no scripts).
- Export one self-contained index.html (inline CSS, data-URL images, meta title/description, favicon from avatar,
  no JavaScript); copy HTML.
- QR code (own encoder) for the address the user will host it on: PNG and SVG download.
- Step-by-step free hosting instructions (GitHub Pages, Netlify Drop, Cloudflare Pages, own site).
- Saved in this browser; save/open a project file (.json).

## Should (full)
- Several pages in the browser, templates (creator, small shop, musician, personal), paste a list of links,
  WhatsApp/email/phone link builders, undo/redo, keyboard shortcuts, URL checks (warn on missing https / typos),
  empty states, mobile 390px with preview toggle, light/dark app UI, S3_SELFTEST, offline service worker.

## Could (later)
- Save-contact (vCard) button, link thumbnails, scheduled links (would need JS in the page), analytics.
