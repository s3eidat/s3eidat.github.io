# S3eidat Tools

**111 free, private tools that run entirely in your browser.** No sign-up, no uploads, no tracking.

### ▶ [Open the tools](https://s3eidat.github.io/)

Every tool is its own open-source repo. Each one is a static page with a strict Content-Security-Policy
(`connect-src 'self'`), so the browser itself blocks any attempt to send your data anywhere.
